Настройки

Панель администратора: откройте Google Таблицу → «FTC Scout» → «Панель администратора». Пароль в коде GitHub не используется.

iPhone: откройте сайт в Safari при наличии интернета, затем «Поделиться» → «На экран Домой». Не удаляйте веб-приложение и данные Safari, пока есть записи в очереди. Перед турниром проверьте тестовую отправку.
